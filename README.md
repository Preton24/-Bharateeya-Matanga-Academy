# BMSSA Modern Website

A fresh React + Vite single-page website for Bharateeya Matanga Samajik Samskrik Academy.

## Run in Antigravity

1. Open this project folder in any IDE.
2. Open the terminal.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Build for deployment

npm run build

The production files will be in `dist/`.
