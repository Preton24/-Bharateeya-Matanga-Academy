# BMSSA Modern Website

A fresh React + Vite single-page website for Bharateeya Matanga Samajik Samskrik Academy.

## Run in Antigravity

1. Open this project folder in Antigravity.
2. Open the terminal.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Build for deployment

npm run build

The production files will be in `dist/`.

## Before publishing

Replace the placeholder contact information in `main.jsx`:
- Phone
- Email
- Address
- WhatsApp number
- Google Maps link

Replace the gallery placeholders with approved academy images.

The enquiry form currently shows a confirmation alert only. Connect it to your preferred form/email backend before production.

## Content source

The initial content was prepared from the publicly available information on the existing BMSSA website:
https://matanga.co.in/
